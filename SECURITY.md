# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Monocle Network - in the Monocle application, its infrastructure, the website, the wiki, or any Monocle Network repository - please report it responsibly.

Do not open a public issue, pull request, or discussion for security vulnerabilities.

For how and where to report, severity criteria, bounty details, and the full disclosure process, see the [Responsible Disclosure Policy](https://monocle.wiki/Policies/Responsible_Disclosure_Policy).

## What to report

- Vulnerabilities in the Monocle application
- Vulnerabilities in Monocle Network infrastructure
- Vulnerabilities in the website or wiki
- Vulnerabilities in any Monocle Network repository

## What not to report here

- General support questions and troubleshooting - see SUPPORT.md
- Trade disputes - these are handled by the dispute resolution process, not a security matter

## Bounties

Monocle Network compensates responsibly disclosed vulnerabilities that are approved under the Responsible Disclosure Policy. See the [policy](https://monocle.wiki/Policies/Responsible_Disclosure_Policy) for eligibility, amounts, and the disclosure process.
