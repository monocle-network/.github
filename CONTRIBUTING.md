# Contributing

Thank you for your interest in contributing to Monocle Network. Monocle is a community-driven, [bootstrapped project](https://monocle.wiki/Policies/Bootstrapped_Operations_Policy): contributors who dedicate their time and skills are compensated in Monero, and all contributions are welcome.

## Contributing code

Code contributions to the Monocle application have their own specific instructions. These are available at [the Monocle Netowrk application's contributing guide](https://github.com/monocle-network/monocle/blob/master/docs/CONTRIBUTING.md).

This document is a general guide for contributing across all other Monocle Network repositories.

## Ways to contribute

- **Compensated roles** - support, arbitration, node operation, development, and other roles compensated from network fees. See the current [help wanted](https://github.com/monocle-network/meta/issues/2) list for roles currently available
- **Community participation** - help peers in community channels, take part in GitHub Discussions, and join discussions on proposals in the [meta repository](https://github.com/monocle-network/meta)
- **One-time tasks** - occasional compensated tasks are posted in the [help wanted](https://github.com/monocle-network/meta/issues/2) list
- **Improve the wiki** - if you think an article should be edited, or a new one should be added, you can [improve the wiki](https://monocle.wiki/Improving_The_Wiki) directly 

## Becoming a compensated contributor

Contributor candidates are expected to demonstrate a track record of useful contributions - in the Monocle community or elsewhere in the Monero space. A good way to start is by being helpful in the community.

Key things to know:

- **Nyms welcome.** Contributors operate under nyms; no personal information is required, only a nym and an XMR address when requesting compensation
- **First month.** Aspiring contributors complete a full calendar month in their role before becoming eligible for compensation
- **Bootstrapped.** Compensation is funded from collected network fees, so distributions are made only when sufficient fees have been collected - delayed distributions are expected in the first months

For the full details, see [Get Involved](https://monoclenetwork.org/get-involved) and the wiki:

- [Contributor roles](https://monocle.wiki/Contributor_Roles) - role descriptions and requirements
- [Contributor compensation](https://monocle.wiki/Contributor_Compensation) - how compensation works
