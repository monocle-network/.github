# Support

## Where to get help

For the current list of support channels, see [monoclenetwork.org/support](https://monoclenetwork.org/support).

SimpleX is the fastest way to reach Monocle, with contributor responses often within 3 hours. On other channels responses might be up to 24 hours.

## Self-help

The [Monocle.Wiki](https://monocle.wiki) is a knowledge base covering things like getting started, backing up and restoring your data, and other how-to guides.

## Get Help on GitHub

If you prefer to get help without leaving GitHub you can open an issue or start a community discussion.

### Create a GitHub issue

If you have experienced a bug in the Monocle application you can create an issue describing it:

- [monocle repository](https://github.com/monocle-network/monocle/issues) - for any problems with the application.

### Open a new GitHub Community Discussion

You can also get help from the community:

- [GitHub Discussions](https://github.com/orgs/monocle-network/discussions) - questions and troubleshooting

## Support language

All support is provided in English.
