# 👋 Hey, this is Monocle Network 

Monocle is building an open source Monero Network based on Haveno Network 🚀

## 🍿 A peer-to-peer network built for the Monero and open source community
Monocle Network 💗 loves helping people buy and sell Monero.

## ❤️ Open Source
Monocle Network is committed to helpinh open source projects to succeed. That's why Monocle gives back to the open source community.

## 🔐 Security
Monocle Netowrk puts users safety as the core of it's operations. If you notice a vulnerability, please follow our project's `SECURITY.md`

## 💬 Feedback
Our [Meta repository](https://github.com/monocle-network/meta) is designed to gather community feedback.

## 💚 Community
Monocle Network is building a community of people interested in privacy, Monero, and open source projects. Get involved in the [discussions](https://github.com/orgs/monocle-network/discussions).
